# Architecture Overview

**Evidence Coordination** is a sovereign-grade enterprise ecosystem with:

- **Frontend**: Single-file HTML + Tailwind + interactive dashboards
- **Backend**: Node.js + Express + PostgreSQL
- **Database**: PostgreSQL with audit logging
- **Security**: Zero-trust principles, immutable audit trail
- **Deployment**: Vercel (frontend), Railway/Render (backend), Neon/Supabase (DB)
